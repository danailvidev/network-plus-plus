Sample traffic

Use a local demo API or public test API. Avoid real tokens, private URLs, cookies, customer data, and production payloads.

Capture setup

Use Chrome stable, a 1440x900 or wider window, dark mode, enabled export redaction, and synthetic data for body capture.

  1. Serve .output/chrome-mv3 locally or load the extension manually.
  2. Use the screenshot harness for synthetic captures, or open a page that generates safe sample traffic.
  3. Capture the views listed above from the real Network++ UI.
  4. Save the files in docs/assets/screenshots/.
  5. Update README.md and docs/index.html if filenames change.

Keep screenshots realistic, readable, and free of secrets.
