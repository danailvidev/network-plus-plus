Sample traffic

Use a local demo API or public test API. Avoid real tokens, private URLs, cookies, customer data, and production payloads.

Capture setup

Use Chrome stable, a 1440x900 or wider window, dark mode, enabled export redaction, and synthetic data for body capture.

Steps

Capture the final screenshots

npm run dev
  1. Load .output/chrome-mv3 from chrome://extensions.
  2. Open a page that generates safe sample traffic.
  3. Open DevTools and select Network++.
  4. Capture the views listed above.
  5. Save the files in docs/assets/screenshots/.
  6. Update README.md and docs/index.html if filenames change.

Keep screenshots realistic, readable, and free of secrets.
